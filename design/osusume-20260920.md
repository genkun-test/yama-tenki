# 「登る山のおすすめ」ページ 設計（2026-09-20）

目的は CLAUDE.md のとおり「楽しく安全で快適に」。このページは**家で次の山を選ぶ**ためのもの。山の中で使うのは既存の天気マップ。

## 完了条件

`python -X utf8 osusume.py` が終了コード 0 で `docs/osusume.html` を作り、スマホ幅で開いて候補が天気つきで並ぶ。上限: 実装2ターン。

| 口 | 取れるもの |

GitHub Actions から取れるかは未検証（計画URLと同じ宿題）。

## 骨格

1. **ビルド時（osusume.py）**: 活動 → 登頂済みの山の集合。候補 = 登頂済みの山の「周辺の山」＋登頂済み自身。各候補にモデルコース1本（最短のコースタイム）を付けて JSON を HTML に埋め込む
2. **端末側**: 候補ごとに山頂標高で Open-Meteo を叩き、**コースタイムぶん連続して好天な枠（気象窓）**を16日先まで探す。窓がある日と出発時刻を出す
3. 並び: 未登頂 → 気象窓が近い順。登頂済みは下に小さく
4. 現在地からは直線距離と車の目安時間（直線×係数。「目安」と明記）。道路経路 API は未検証なので初版では使わない
5. 取れた結果は localStorage に置き、電波が無いときは前回の結果を時刻つきで出す
6. ユーザーID はリポジトリに書かない（環境変数 `YAMAP_USER`、Actions では Secret）

## 仮提案の採否

- 登頂済みを下に小さく: 採用
- おすすめの日と時間帯: 採用。「晴れの日」ではなくコースタイムぶんの連続窓で判定する（Gemini 段3）
- 往復の所要時間: 採用（モデルコースのコースタイム）
- 現在地からの移動時間と距離: 距離は採用、時間は目安表示
