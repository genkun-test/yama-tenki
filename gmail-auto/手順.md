# Gmail → 自動更新 のつなぎ込み（1回だけ・2か所）

## 1. Apps Script を公開する

1. https://script.google.com/home/projects/create を開く（bonmown@gmail.com で）
2. 最初から入っている `function myFunction() {…}` を全部消し、
   `C:\Memory\NewWorld\NewAI\yama-tenki\gmail-auto\Code.gs` の中身を貼って保存（Ctrl+S）
3. 右上「デプロイ」→「新しいデプロイ」→ 種類の歯車で「ウェブアプリ」
   - 次のユーザーとして実行: **自分**
   - アクセスできるユーザー: **全員**
4. 「デプロイ」→ Gmail を読む許可を求められるので承認
   （「このアプリは確認されていません」と出たら「詳細」→「（安全ではないページ）に移動」。自分で作ったスクリプトなので問題なし）
5. 表示された **ウェブアプリの URL**（`https://script.google.com/macros/s/…/exec`）をコピー
   - ブラウザで開いて、`https://yamap.com/plans/code/…` が1行出れば成功

## 2. GitHub に貼る

1. https://github.com/genkun-test/yama-tenki/settings/secrets/actions/new を開く
2. Name: `PLAN_SRC` ／ Secret: さっきの URL → 「Add secret」

以上。あとは毎時17分に自動で作り直される。すぐ試すなら
https://github.com/genkun-test/yama-tenki/actions/workflows/update.yml の「Run workflow」。

## このスクリプトが見えるもの

Gmail のうち `noreply@yamap.co.jp` からのメール本文だけを検索し、計画URLの1行だけを返す。
URL を知っている人はその1行を読めるので、ウェブアプリの URL は人に渡さない。
